## Intent

A funny, satirical late-night infomercial for llmtsc. The vibe coder's dream is to go back to a life before AI
and do real development again — but we've forgotten all syntax because we haven't written a letter of code in years.
How do we get back without knowing the syntax? llmtsc: it turns any code that remotely looks like a TypeScript React
project into something that actually executes. "This works for Angular too, but no one really uses Angular, so why
bother." Make a compelling and ridiculous case for the product.

## Customizations

- Voiceover via the ElevenLabs CLI — audition and pick an awesome over-the-top infomercial announcer voice.
- SFX via ElevenLabs text-to-sound-effects: record scratch, cha-ching, sad trombone, crowd "ooooh".
- Cheesy 90s infomercial music bed via ElevenLabs music, ducked/carved under the VO.
- Jokes grounded in the real README: `fulName`→`fullName`, `conole.log(users.lenght)`, "source files never modified",
  cached answers, `--no-llm` = plain tsc, `npm i -D llmtsc` as the CALL NOW.
